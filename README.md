# portfolio-content

This repository contains all the content used by my personal portfolio website (`portfolio-laolou`).  
It serves as the "database" for the portfolio, storing:

- Project details (name, description, technologies, GitHub links)
- Hobbies details
- Contact details
- Skills details (name of technology, level)
- Images for projects and portfolio sections
- Other structured data for dynamic rendering (in JSON format)
- CV file (PDF)

## Purpose

The main portfolio site ([portfolio-laolou](https://github.com/LaolouRavon-Laforest/portfolio-laolou)) fetches its content from this repository.  
This separation allows easy updates of portfolio content without touching the website code itself.
